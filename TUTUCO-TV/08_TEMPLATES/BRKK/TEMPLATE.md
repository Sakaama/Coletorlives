# TUTUCO TV — BRKK

## FORMATO BASE

- Canvas: 1080x1920
- Formato: 9:16
- FPS inicial: 30
- Destinos: TikTok / Reels / Shorts / Kwai
- Edição final: CapCut
- Objetivo: produção rápida sem sacrificar qualidade

---

# 🔥 TEMPLATE VISUAL

## Usar quando houver

- gameplay
- reação a vídeo
- conteúdo sendo assistido
- abertura de cartas/packs/caixas
- desafio
- fail
- vitória/derrota
- acontecimento visual
- streamer mostrando algo na tela

## Layout

┌────────────────────────────┐
│                            │
│       CÂMERA STREAMER      │
│                            │
├────────────────────────────┤
│      kick.com/brkk            │
├────────────────────────────┤
│                            │
│     GAMEPLAY / CONTEÚDO    │
│                            │
│                            │
└────────────────────────────┘

## Regra editorial

O próprio conteúdo da live funciona como B-roll.

Evitar adicionar assets desnecessários.

Fluxo:

RAW
→ câmera em cima
→ conteúdo embaixo
→ lower/Kick
→ legenda automática
→ correção
→ ajustes rápidos
→ exportar

Meta futura:
5–10 minutos de edição por corte simples.

# ✂️ TEMPLATE TALKING

## Usar quando houver

- história
- opinião
- relato
- notícia
- conversa
- assunto interessante sem ação visual suficiente

## Layout

┌────────────────────────────┐
│                            │
│   FOTO / PRINT / B-ROLL    │
│      VÍDEO / CONTEXTO      │
│                            │
├────────────────────────────┤
│      kick.com/brkk            │
├────────────────────────────┤
│                            │
│       CÂMERA STREAMER      │
│                            │
└────────────────────────────┘

## Regra editorial

No TALKING a hierarquia é invertida:

CONTEÚDO/B-ROLL EM CIMA
CÂMERA EMBAIXO

O asset superior deve acompanhar o assunto.

Exemplos:

falou de evento → imagens do evento
falou de pessoa → imagem/vídeo da pessoa
falou de notícia → print/contexto
falou de vídeo → trecho correspondente

Evitar deixar uma única imagem estática durante todo o corte.

Talking deve ser priorizado quando a fala justificar o trabalho adicional.

# LEGENDAS

- legenda automática como ponto de partida
- revisar erros antes da exportação
- não cobrir rosto
- não cobrir informação importante
- manter leitura confortável no celular

---

# CTA

CTA do TUTUCO TV somente quando permitido pelas regras da campanha.

Nunca substituir elementos obrigatórios do criador/campanha.

---

# PRINCÍPIO DO TUTUCO TV

VISUAL:
câmera em cima + conteúdo embaixo.

TALKING:
conteúdo/B-roll em cima + câmera embaixo.

O objetivo é transformar um RAW aprovado em corte publicável
com o menor trabalho repetitivo possível.
